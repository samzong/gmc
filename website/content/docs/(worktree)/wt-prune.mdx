---
title: Prune
description: Remove worktrees whose branches are merged.
---

`gmc wt prune` removes worktrees whose branches are already merged into the base branch.

## Usage

```bash
gmc wt prune
```

## Preview

```bash
gmc wt prune --dry-run
```

## PR-aware cleanup

```bash
gmc wt prune --pr-aware
```

## Stale local branches

Merged branches that no longer have a worktree are left alone by default. Add
`--branches` to delete them as well; combine with `--pr-aware` when the repository
uses squash merges, since ancestry checks cannot see those.

```bash
gmc wt prune --branches --pr-aware --dry-run
gmc wt prune --branches --pr-aware
```

## Base branch

```bash
gmc wt prune -b main
```

## Notes

Use `--force` only when you accept losing dirty worktree changes.
