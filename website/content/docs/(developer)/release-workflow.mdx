---
title: Release Workflow
description: Release gmc with tags and GoReleaser.
---

`gmc` uses tag-driven releases.

## Validate locally

```bash
make check
make build
goreleaser check
goreleaser release --snapshot --clean
```

## Create a tag

```bash
gmc tag
```

## Homebrew

The centralized [samzong/homebrew-tap](https://github.com/samzong/homebrew-tap) automation scans gmc releases and updates `Formula/gmc.rb`.

## Notes

GoReleaser generates release notes from commits in the tagged release. Release automation does not open changelog pull requests. `CHANGELOG.md` keeps historical entries.
